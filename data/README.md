# Dataset

The complete datasets used in this work are not included in this repository because they exceed GitHub's file size limits (~18 GB).

The study uses monthly oceanographic products from 2015–2024 including:

- Sea Surface Temperature (SST)
- Sea Surface Height (SSH)
- Salinity
- Dissolved Oxygen
- Chlorophyll-a

Spatial Resolution:
0.25°

Study Region:
Tropical Indian Ocean

Users may obtain the datasets from:

• Copernicus Marine Data Store
https://marine.copernicus.eu/

After downloading, place them in

data/raw/

and run

src/preprocessing/

to reproduce the processed datasets.
